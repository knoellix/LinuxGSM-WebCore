# Logging-System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strukturiertes Logging für LinuxGSM-WebCore mit drei Ebenen: Fehler immer in `miniserv.error`, Admin-Aktionen immer im Webmin Actions Log, Debug-Details nur wenn `debug_logging=1` in der Modulkonfiguration gesetzt ist.

**Architecture:** Neue Datei `src/lib/logging.pl` definiert drei Funktionen (`log_error`, `log_action`, `log_debug`) im `main`-Namespace. CGIs laden sie via `require './lib/logging.pl'`; die Libs (`jobs.pl`, `acl.pl`) rufen sie ohne eigenes `require` auf, weil sie zur Laufzeit in `main::` verfügbar sind. `warn` landet automatisch in `/var/webmin/miniserv.error`; `webmin_log()` schreibt in den Webmin Actions Log. In Tests verwenden die Libs leere Stubs aus `t/stubs.pl`.

**Tech Stack:** Perl 5, Webmin Core (`webmin_log`, `warn`), TAP-Tests

```perl
# LinuxGSM-WebCore - Structured logging
use strict;
use warnings;

our (%config);

sub log_error {
    my ($msg) = @_;
    warn "[LGSM-ERROR] $msg\n";
}

sub log_action {
    my ($action, $object, $params) = @_;
    $params //= {};
    &webmin_log($action, 'lgsm', $object, $params);
}

sub log_debug {
    my ($msg) = @_;
    return unless $config{debug_logging};
    warn "[LGSM-DEBUG] $msg\n";
}

1;
```
